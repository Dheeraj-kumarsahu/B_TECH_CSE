## ⚙️ How to Run a Program

**1. Clone the repository**

```bash
git clone https://github.com/<your-username>/<repository-name>.git
cd <repository-name>
```

**2. Compile with GCC**

```bash
gcc filename.c -o filename
```

**3. Run it**

```bash
# Linux / macOS
./filename

# Windows
filename.exe
```
